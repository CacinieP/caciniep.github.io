# caciniep.github.io

Personal portfolio for **Cace — AI Builder with Linguistic Acumen**.

The site is intentionally build-free: semantic HTML, one CSS file, and no runtime
dependencies. It is designed for direct deployment through GitHub Pages.

## Local preview

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Design language

- editorial paper palette: cream, ink, mint, coral
- bilingual Chinese/English hierarchy
- syntax-tree and agent-graph visual metaphors
- strong borders, numbered labels, and system-log details
