LINGUISTIC ACUMEN

语言不是界面之后的文案。
它是系统之前的架构。

LANGUAGE IS NOT COPY AFTER THE INTERFACE.
IT IS ARCHITECTURE BEFORE THE SYSTEM.

我把语言学训练带进 AI 构建过程：识别真正的意图，判断上下文边界， 为接口建立共享语法，再用反馈让系统持续修正。

01 / SYNTAX

先让关系站稳。

语法不替内容做决定；它让复杂的依赖、角色与动作仍然可以被理解。

02 / CONTEXT

意义发生在上下文里。

Agent 的可靠性，常常不取决于更大的模型，而取决于被保留下来的语境。

03 / INTERFACE

让不同系统知道怎样说话。

好的接口不是消除差异，而是为差异建立一套足够清晰的共同语言。

[ parse ] 读懂意图 → [ model ] 组织语境 → [ build ] 让理解运行
